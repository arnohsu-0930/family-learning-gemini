# 全家備課與學習小幫手（Gemini 純淨直用版）

這是一套專為**老師備課、學生複習、全家人一起學新東西**設計的零門檻 AI 小幫手說明包。
**核心原則：所有日常事情都優先透過 Google Gemini 無腦完成（0 安裝、不動用 Antigravity 額度）！** 只要打開 Gemini 網頁版或手機 App，就能像傳 LINE 一樣用「數字選單（1、2、3）」一步步完成：

- 老師出 Word 考卷（可學習過去考卷版面，自動產出題目卷＋答案解析卷）
- 做出點開就能玩的「互動複習小遊戲」與「左觀念右練習小網頁」
- 製作課堂 PowerPoint 簡報、一張看懂重點的彩色海報、自動播放動畫小網頁
- 拍照上傳課本或作業，用最溫柔白話的方式一步步講解
- **（不強制，需要時再看）** 若在私人電腦想做 Gemini 無法直接產出的「動畫版簡報／MP4 教學影片」或大量檔案批次處理，內附兩套免費選配指南：**精簡 Python 工具箱** 與 **OpenCode 桌面版（串接輝達 NVIDIA 免費模型）**。

## 怎麼開始用？（三種超簡單方式，選一種就好）

### 方式 1：最無腦，直接貼這段話給 Gemini（0 設定，手機電腦都能用）

打開 [Google Gemini](https://gemini.google.com/)，直接複製下面整段話貼上去送出：

```text
哈囉！家人推薦我用這套學習與備課小幫手，請幫我讀取這個公開網頁裡的 SKILL.md 和 00_新手從零開始指南.md：
https://github.com/arnohsu-0930/family-learning-gemini

請全程用最簡單的白話（不要用任何電腦專有名詞），先問我現在用的是私人電腦／手機平板，還是學校／公司公用電腦，再用數字選單一步一步帶我開始！
```

### 方式 2：最推薦，設成專屬「Gem」或匯入「Skill」（只設一次，以後點一下就開用）

1. **設成專屬 Gem（所有 Google 帳號都能用）**：
   - 在 Gemini 網頁版左側點 **「Gem → 新增 Gem」**，取名「備課與學習小幫手」。
   - 點開本頁面的 [`SKILL.md`](./SKILL.md)，把裡面的文字全選複製、貼進「操作說明」。
   - （老師強烈推薦）順手把你過去出過的 2～3 份舊考卷上傳到「知識」區，以後出考卷就會自動照你的風格排版！
2. **匯入成 Gemini Skill（若帳號有技能管理功能）**：
   - 直接將本資料夾的 `SKILL.md`（或打包好的 `family-learning-gemini-skill.zip`）上傳匯入即可。

### 方式 3：進階選配（不強制安裝，只有私人電腦需要時才看）

- 想讓電腦點兩下跑批次工具（掃描 PDF 轉字、轉影片）：看 [`01_選配電腦Python工具箱.md`](./01_選配電腦Python工具箱.md)
- 想裝免費電腦 AI 幫手做「動畫版簡報／教學 MP4 影片」：看 [`02_選配進階工具_OpenCode免費安裝與輝達模型指南.md`](./02_選配進階工具_OpenCode免費安裝與輝達模型指南.md)
